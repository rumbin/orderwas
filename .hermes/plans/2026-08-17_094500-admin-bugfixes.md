# Bug Fixes & UX Improvements — Admin Panel

> **Created:** 2026-08-17 after live sandbox review by Philipp.
> **Status:** All 4 issues fixed and verified.

## Changes Made

### Issue 1: Admin sidebar collapses on mobile ✅
- Sidebar is now off-screen on mobile (`-translate-x-full`), shown via hamburger menu
- Mobile header bar shows current tab name + hamburger button
- Sidebar auto-collapses after tab selection
- Desktop layout unchanged (`md:translate-x-0`)

### Issue 2: Delete button with confirmation + error handling ✅
- Delete button uses trash icon (SVG) instead of plain text
- Confirmation dialog before deletion
- Error display (e.g. 409 "referenced by orders") shown in dialog
- 5 new client-side tests covering all delete scenarios

### Issue 3: Availability toggle no longer clears product list ✅
- Toggle now uses optimistic local state update (flips `available` flag in-place)
- No more cache-clearing + re-fetch pattern that caused empty flash
- `loadProducts` always fetches fresh data for create/delete operations

### Issue 4: "Neue Bestellung" button on Orders page ✅
- Prominent blue button in Orders page header: "+ Neue Bestellung"
- Replaces the previous "← Produkte" link
- Navigates to order page for fresh order
